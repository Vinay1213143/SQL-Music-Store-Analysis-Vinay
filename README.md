# 🎵 SQL Music Store Analysis

## 📌 Project Overview

This project focuses on analyzing an online music store database using SQL. The goal is to explore customer behavior, sales performance, artist popularity, and business trends through real-world SQL queries.

By working on this project, you can strengthen your SQL skills while solving practical business problems and generating meaningful insights from data.

---

## 🎯 Objectives

* Analyze customer purchasing behavior
* Identify top-selling artists and tracks
* Discover high-revenue countries and cities
* Understand customer spending patterns
* Generate business insights using SQL queries
* Practice real-world database analysis techniques

## 📈 Business Questions Solved

Some of the analysis performed in this project includes:

### Easy Level

* Who is the senior-most employee based on job title?
* Which countries have the most invoices?
* What are the top invoice totals?
* Which city generates the highest revenue?
* Who is the best customer?

### Moderate Level

* Identify Rock music listeners.
* Find the top Rock artists.
* Determine tracks longer than the average song length.

### Advanced Level

* Calculate customer spending on artists.
* Find the most popular music genre by country.
* Identify the highest-spending customer in each country.
